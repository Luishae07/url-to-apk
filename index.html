Turn any website into an Android app

Paste an address, press the button, and get an .apk that opens the site full screen, with its own icon and colour. It is built for free by GitHub, with no sign-up for us.

GitHub opens with the request filled in. Press Submit new issue there (you need a free GitHub account). This page then shows the progress and the download.

How to install it

  1. Open the download link on your Android phone.
  2. Open the downloaded file. Android asks you to allow installing from this source, once.
  3. Done. The app is on your home screen with the website's icon.

Good to know

  • The app is a full-screen view of the website. Links to other websites open in your normal browser.
  • Only https websites work. It always shows the live website, so it is as up to date as the site.
  • The file is signed with a standard test key. It installs fine, but it is not for the Play Store, and an update built later may need the old app removed first.
  • Only make apps for websites you own or may use this way. Please don't make look-alikes of other people's sites.
